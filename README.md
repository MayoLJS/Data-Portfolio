## 1. NHS Scotland Elective Care Analytics
* **Business Problem:** Analyzing elective care wait times across health boards to identify operational bottlenecks and improve patient throughput.
* **Tools Used:** SQL Server (T-SQL), Advanced SQL, SSIS, Excel
* **Key Outcome:** Extracted actionable diagnostic intelligence by modeling a "Breach Density" metric and calculating disparity ratios to identify the regions and complex medical specialties suffering the most severe bottlenecks.

## 2. Automated Football Analytics
* **Business Problem:** Tracking weekly team performance and match statistics requires manual spreadsheet updates, causing reporting delays and increasing the risk of human error.
* **Tools Used:** Python (Pandas, Requests), REST APIs, GitHub Actions
* **Key Outcome:** Engineered a zero-touch, automated cloud ETL pipeline that automatically fetches, normalizes, and stages a rolling daily feed of global football match statistics.

## 3. ScotRail Delay Attribution
* **Business Problem:** Public-facing metrics incorrectly place the burden of system delays on the Train Operating Company (TOC) rather than the external infrastructure provider.
* **Tools Used:** Python (Pandas, Seaborn, Matplotlib, Regex)
* **Key Outcome:** Analyzed ORR periodic statistics to prove external infrastructure failures caused the majority of delays, delivering a strategic recommendation to aggressively dispute penalties and implement targeted crew resourcing.
* **🔗 [View Project Folder](./03_Scotrail_Delay_Attribution/)**

## 4. Premier League Hub & Prescriptive FPL Optimizer
* **Business Problem:** Moving beyond descriptive analytics, this project solves complex constraint-based resource allocation problems to identify the mathematically optimal 15-player fantasy squad.
* **Tools Used:** Python 3, Streamlit, PuLP (Integer Linear Programming), Pandas, Plotly, REST APIs
* **Key Outcome:** Built a live Full-Stack Data Application leveraging a Knapsack Optimization engine, rolling predictive match analytics, and a dynamic player scout card.
* **🔗 [View Project Folder](./04_Fantasy_PL/)**

## 5. UK Household Financial Resilience Analysis
* **Business Problem:** Investigating the financial health of UK households to identify a critical "Awareness Gap" where objective debt levels accelerate while subjective financial stress remains at record lows.
* **Tools Used:** Databricks (Lakehouse Architecture), SQL, Python (Pandas, Seaborn, Matplotlib)
* **Key Outcome:** Processed Bank of England survey data through a Medallion Architecture to reveal that financial risk is heavily concentrated in the 25-34 age bracket, with over 80% of social renters classified as financially fragile.
* **🔗 [View Project Folder](./05_UK_household_financial_resilience/)**

## 6. Global Sovereign Debt & Creditor Concentration Monitor
* **Business Problem:** Traditional reporting focuses on total debt-to-GDP, but this project engineers a tool to isolate Creditor Concentration Risk and identify over-reliance on single lending blocks.
* **Tools Used:** Power Query (ETL), Power Pivot, DAX
* **Key Outcome:** Implemented a Three-Tier Data Architecture that identified critical macro-level shifts (e.g., a 28% rise in defaults to China in 2023) and established automated risk threshold alerts for mandatory regulatory review.
* **🔗 [View Project Folder](./06_GlobalSovereignDebt_&_CreditorConcentrationMonitor/)**
